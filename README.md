# License Plate Recognition System

An AI-based License Plate Recognition System using:

- Flask
- YOLOv8
- EasyOCR
- OpenCV

## Features

- Vehicle image upload
- Live camera detection
- OCR extraction
- Plate history
- Dark mode UI

## Technologies

- Python
- Flask
- YOLOv8
- EasyOCR
- OpenCV
- SQLite

## Deployment

Hosted on Render.
